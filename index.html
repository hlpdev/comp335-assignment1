#Projects

perch/

August 2026 - present in development perchapp.org

A notch overlay for Windows. Music, calls, volume, and user widgets live in one pill at the top of the screen: present when something happens, gone when it's done. Written in C++20 on SDL3 and OpenGL, with the UI rendered by CEF (Chromium Embedded Framework) off-screen and composited over the desktop through a click-through layered window.

Utilized frontier models and agentic workflows to design Perch's interface, arbitration engine, transition protocol, mod system, voice pipeline, and Perch Studio, with me directing the systems design & architecture, ruling on behavior, and live-testing every build. Providers feed a C++ core that owns all state. The arbitration engine ranks what is present by urgency and the user's settings, chooses features to display, and solves the layout. Each solve is pushed to the view as enter, exit, move, and morph/modify operations that spring-animate features into place. Every widget, built-ins included, is a sandboxed Luau mod loaded via the filesystem or through the Steam Workshop. Mods are written against a strictly typed API with scoped permissions. Perch Studio, a standalone mod IDE shipped as its on Steam tool, uses Monaco with luau-lsp over our API, displays previews through Perch's real rendering system, and publishes mods straight to the Steam Workshop.

C++20 SDL3 OpenGL 3.3 CEF (Chromium Embedded Framework) Win32 Luau CMake HTML CSS Steamworks

zomboid-map/

August 2026 - present live zomboidmap.com stats.zomboidmap.com

An interactive map for Project Zomboid Build 42, built to replace the unstable official map. A C++ ingest pipeline reverse engineers the game's binary map and texture formats and renders the entire Kentucky world into a tile map. A React frontend layers game data on top.

Features a multithreaded isometric renderer with per-thread caches and a WebP tile pyramid, per-floor output enables floor switching and basement views, A* route planning over the street network with driving and walking ETAs, loot finder, base-finder, zombie heatmap, map zones, room interiors, vehicle spawn info, and more.

C++20 TypeScript React Cloudflare Pages Cloudflare R2 Cloudflare Workers
